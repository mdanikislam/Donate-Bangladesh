What is the DOM?
The Document Object Model (DOM) is a programming interface that allows developers to interact with and manipulate HTML and XML documents. It represents the document as a structured tree of nodes, where each node corresponds to a part of the document (like elements, attributes, or text).
How can you access elements in the DOM using JavaScript?
You can access DOM elements in JavaScript using various built-in methods provided by the document object. The most common methods include getElementById to select an element by its ID, getElementsByClassName to retrieve all elements with a specific class name, and getElementsByTagName to get elements by tag name like

Explain the differences between getElementById, getElementsByClassName, and getElementsByTagName.
getElementById returns a single element that matches the provided ID and is the fastest method for accessing an element. It is ideal when working with a unique element on a page. getElementsByClassName returns a live HTMLCollection of all elements with the specified class. This means it updates automatically if the DOM changes. getElementsByTagName also returns a live collection, but it targets all elements with a specific tag, like "div" or "li". Both of these return collections and require iteration if you want to manipulate each element individually.
What is the DOM?How do you stop event propagation in the DOM?
To prevent an event from bubbling up the DOM tree, you can use the stopPropagation() method inside the event handler. This tells the browser to stop the event from being passed to ancestor elements. There is also stopImmediatePropagation(), which stops the event from calling any other listeners on the same element.
